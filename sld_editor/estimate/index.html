Assembly Builder — user guide

Simple flow. You do not need user accounts — only a license code.

  1. Activate with your license code (same as the phone).
  2. Edit kits — open a structure / conductor / guarding kit and add Mat & Lab items. Save stays on this computer.
  3. Custom structure — for poles not in the standard list (+ Custom structure).
  4. Suggest change (if allowed) — send a kit edit for review (works even if the kit is Final). Does not go to phones yet.
  5. Accept / Reject (approver) — Suggestions tab. Accept merges as Draft; tick Final when you approve the content.
  6. Final — ready for estimates. Users can still suggest later edits.
  7. Estimate tab — import phone workspace JSON and generate the final BOQ on desktop (primary).
  8. Publish to app (admin) — uploads Mat/Lab + kits online so phones can download.
  9. Licenses (admin) — create / extend / block rental codes in the app (server checks can_approve).

Permissions on your license

  • Unlocked only — edit kits locally; Export / Import / Reset.
  • Suggest — also Suggest change.
  • Approve (admin) — Suggestions, Publish to app, Licenses tab.

Greyed-out buttons mean your license does not include that permission. Ask the seller to turn on can_suggest or can_approve.
